What this page is showing

Alice and Bob are two people having a private conversation. The relay in the middle is the server that carries their messages, the way a messaging company's servers would. The question this project asks is: how much can that server in the middle actually see?

  1. Press Send under Alice. The message appears as ordinary readable text under both Alice and Bob.
  2. Look at the dark middle column. The same message is there, but only as a counter and a block of hexadecimal. That is everything the server gets.
  3. The bar below compares a safety number that Alice and Bob each compute independently. Matching numbers mean nobody is impersonating either side.
  4. Then run the checks in the table further down. Each one runs real Python and reports what actually happened, including the two attacks that succeed.

3. What holds and what does not

  • Holds: the relay cannot read message content, cannot alter a message without the tag check failing, cannot renumber records, and cannot replay a captured one.
  • Does not hold: an active attacker who sits in the handshake gets both keys and reads everything, because plain Diffie-Hellman proves the other side can do the maths but not who they are. Comparing safety numbers is the only warning, and only if a human actually checks.
  • Does not hold: message length, timing and direction are visible to the relay. Check E recovers exact plaintext lengths from the wire sizes alone.
